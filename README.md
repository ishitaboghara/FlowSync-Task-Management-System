# FlowSync – Smart Task & Productivity Hub

FlowSync is a full-stack task and productivity management web application developed as a final year project. The application helps users manage tasks, projects, and team activities through a simple and modern interface.

It includes authentication, task management, project tracking, team collaboration, and activity logging features.

---

## Features

* User Registration & Login
* JWT Authentication
* Create, Update & Delete Tasks
* Task Priority & Status Management
* Project Management
* Team Collaboration
* Activity Logging
* Dashboard with Task Statistics
* Dark Mode UI

---

## Tech Stack

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* JWT Authentication

## Running the Project

```bash id="5o18ti"
git clone https://github.com/your-username/FlowSync.git
cd FlowSync/backend
npm install
npm run dev
```

Import the database:

```bash id="1v2hca"
mysql -u root -p flowsync_db < database/schema.sql
```

Open the frontend using Live Server.
